01 / Mapa de testes

Oito formas de
encontrar problemas.

Cada estratégia possui um objetivo diferente. Juntas, elas ajudam equipes a construir sistemas mais confiáveis, seguros e fáceis de utilizar.

01

Testes Unitários

Validam pequenas partes isoladas do código, como funções e métodos.

Jest JUnit
02

Testes de Integração

Verificam se diferentes módulos, APIs e serviços funcionam corretamente juntos.

Postman API
03

Testes de Sistema

Avaliam o sistema completo simulando comportamentos reais do usuário.

Selenium E2E
04

Performance

Mede o comportamento do sistema sob diferentes níveis de carga.

JMeter Latência
05

Segurança

Procura vulnerabilidades e riscos que possam comprometer a aplicação.

OWASP ZAP
06

Usabilidade

Analisa se o sistema é fácil, intuitivo e eficiente para seus usuários.

Nielsen UX
07

Automação

Automatiza cenários repetitivos para aumentar velocidade e confiabilidade.

Cypress Playwright
08

BDD / TDD

Trabalha com ciclos de desenvolvimento orientados por testes e comportamento.

Cucumber Red-Green
02 / Na prática

Testando uma
função simples.

Os testes unitários são um bom ponto de partida para entender como a qualidade pode ser verificada diretamente no código.

O que estamos verificando?

Se a função recebe dois números e retorna corretamente a soma deles.

JavaScript
exemplo.test.js
Jest 
function somar(a, b) {
    return a + b;
}

test("deve somar dois números", () => {

    expect(somar(5, 3))
        .toBe(8);

});
Teste aprovado
Resultado esperado: 8
